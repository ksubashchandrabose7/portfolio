# Portfolio - Subash Chandra Bose K

A modern, responsive personal portfolio website showcasing UI/UX design and development work.

## 🚀 Features
- **Clean Full-Width Responsive Design**: Optimized for all screen sizes from mobile to ultra-wide desktop.
- **Dark / Light Theme Toggle**: Seamless transition between dark and light modes.
- **Fullscreen Mode**: 1-click browser fullscreen presentation view.
- **Interactive Animations**: Custom cursor, particle background, smooth scrolling, and scroll reveal animations.
- **Projects & Education Showcase**: Highlighting UI/UX Figma prototypes, development projects, and certifications.

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript (Vanilla ES6+)
- FontAwesome Icons & Google Fonts (Space Grotesk, Inter)
